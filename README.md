Dreamcore Unity MVP - Horror Skeleton for Chapter 1 (First-Person) and Chapter 2 (Boat/CCTV)

This skeleton provides runtime maze generation for Chapter 1, three valves required to unlock a rubber boat, and a simple transition to Chapter 2 with a CCTV-like 15-second watch.

Notes:
- Import into Unity; create the actual Scenes under Assets/Scenes or enable runtime maze generation.
- Attach Stage1MazeGenerator to a GameObject in Chapter1 scene to instantiate walls and valves.
- The CTX features (cutscenes, crouch, boat) are scaffolded; you will need to implement visuals and assets to make it fully functional.
